What If the Old Installation Is Still Listed?

When moving from an old computer to a new one, the previous device may still appear in your account. If your account provides device management options, review the listed computers and follow the instructions available there.

Avoid removing a device unless you are sure it is the computer you no longer use. Keeping your account information organized can make future installations easier.

Common Reinstallation Problems

The Installer Will Not Download

Check your internet connection and try again. Make sure your browser is functioning normally and that you have sufficient storage space on the computer.

I Cannot Remember My Account Password

Use the available password recovery option associated with the account. Check the email inbox connected to your account for recovery instructions.

My Purchase Is Not Showing

Make sure you are using the same account that was used for the original purchase. Signing into a different email account can make it appear as though the purchase is missing.

Windows Blocks the Installation

Review any Windows security prompts carefully. If you started the installer yourself, follow the legitimate instructions shown on screen. Avoid running files from unknown sources.

The Software Was Previously Installed

If an older installation remains on the computer, follow the current installation instructions rather than repeatedly launching the same installer. If necessary, restart Windows before trying again.
